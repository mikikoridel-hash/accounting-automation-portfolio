V3: Excel data consolidation and cleaning (synthetic data only)
1. Copy weekly Excel files into raw/. Each has two facility tabs and an excluded Invoice Review tab.
2. Run python ImportTool.py (Python 3.12+, standard library only), or run the existing GitHub Actions workflow.
3. Open output/MasterData.csv (raw names preserved), CleanedData.csv (standard names), MappingQC.csv (unmapped names), ImportLog.csv.
4. Change mapping/AgencyMap.csv or FacilityMap.csv to resolve an unmapped alias; rerun without editing source files.
5. Run python test_import.py for replacement/deletion tests.
Existing V2 state.json is not compatible; use a fresh output directory for V3. GitHub Actions starts fresh each run; incremental behavior is tested within one run.
This is a limited demo with fixed timesheet headers. Invoice Review is a placeholder; invoice generation and partial-shift premiums are not yet implemented.
